Sesi 1 Integrasi Google Gemini API ✅ Diimplementasikan
Menggunakan SDK resmi google-genai v2.x via genai.Client dengan percakapan bersambung (multi-turn).
Sesi 1 Pengelolaan API Key & Environment ✅ Diimplementasikan
Dikelola aman via .env dan Streamlit Secrets, dengan fallback input manual di sidebar.
Sesi 1 Prompting Dasar (Role & Instructional) ✅ Diimplementasikan
Persona "Mintel", aturan gaya bahasa, dan batasan konteks ketat di SYSTEM_INSTRUCTION.
Sesi 1 Streaming Text Output ✅ Diimplementasikan
Menggunakan generator chat.send_message_stream() untuk respons teks real-time sub-detik.
Sesi 1 Etika AI, Privasi & Keamanan Data ✅ Diimplementasikan
Notifikasi perekaman data, sanitasi CSV Formula Injection (_sheet_safe), dan batas karakter input.
Sesi 1 Hyperparameter Tuning (temperature, dll.) 🔄 Replaced by Model Default Preset
Menggunakan konfigurasi default bawaan model demi menghindari konflik parameter dan menjamin 100% kompatibilitas universal lintas 6 model pada antrean fallback.
Sesi 1 Native Function Calling Gemini 🔄 Replaced by Regex Handoff Engine
Logika pemicu kontak sales ditangani secara deterministik menggunakan filter Regex Python di level aplikasi, sehingga 100% konsisten tanpa membuang kuota round-trip function calling.
Sesi 1 Prompting Lanjutan (CoT, ToT, ReAct) 🔄 Replaced by Direct Instructional Prompting
Menggunakan gaya konsultasi langsung yang ramah dan cepat (Direct Advisory) sesuai kebutuhan pre-sales, menghindari coretan penalaran analitis bertele-tele di layar calon pelanggan.
Sesi 2 Konsep Retrieval & Anti-Halusinasi ✅ Diimplementasikan
Memuat 6 dokumen panduan Markdown dari folder knowledge/ langsung ke System Prompt secara dinamis.
Sesi 2 LangChain Framework 🔄 Replaced by Native SDK
Digantikan dengan integrasi langsung SDK resmi google-genai untuk mengeliminasi dependensi pihak ketiga (no bloatware), mempercepat waktu booting, dan meringankan aplikasi.
Sesi 2 Vector Database & Embeddings (FAISS/Chroma) 🔄 Replaced by In-Context Grounding
Memanfaatkan large context window Gemini (1M+ token) untuk memuat seluruh 6 dokumen katalog (~10.000 token) secara utuh 100%, mengeliminasi resiko salah baca tabel spesifikasi akibat pemotongan teks (chunking loss).
Sesi 2 Meta LLaMA & Groq Cloud API 🔄 Replaced by Gemini Multi-Model Stack
Fokus penuh pada ekosistem Google Gemini karena batas kuota gratis Groq (Tokens Per Minute) sangat sempit (~6K–30K TPM) yang rawan rate limit saat menginjeksi Knowledge Base, sedangkan Gemini menyediakan 250K TPM dan 500 RPD per model Flash-Lite.
Sesi 3 Streamlit UI & Chat Components ✅ Diimplementasikan
UI interaktif dengan st.chat_message, st.chat_input, st.sidebar, st.columns, dan custom CSS branding.
Sesi 3 Session State & History Management ✅ Diimplementasikan
Manajemen histori percakapan via st.session_state dengan limit sliding window MAX_HISTORY_TURNS = 20.
Sesi 3 Caching Data & Resource ✅ Diimplementasikan
@st.cache_data(ttl=300) untuk membaca file knowledge base dan @st.cache_resource untuk Google Sheets.
Sesi 3 Cloud Deployment ✅ Diimplementasikan
Dideploy live dan dapat diakses publik di Streamlit Community Cloud.
Sesi 3 Deliverables Final Project ✅ Diimplementasikan
Repositori GitHub, screenshot UI (UI_Screenshot.png), dan dokumentasi lengkap di README.md.
Sesi 3 Autonomous Multi-Step AI Agent (Agentic Loop) 🔄 Replaced by Guided Pre-Sales Consultant
Mengadopsi arsitektur asisten kualifikasi kebutuhan dengan prinsip Human-in-the-Loop (dialihkan ke Sales Rep manusia saat bertransaksi) demi menjaga keamanan komersial dan responsivitas interaksi.
